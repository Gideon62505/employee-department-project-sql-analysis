Employee, Department & Project Management SQL Analysis

Project Overview
This project focuses on analyzing employee, department, salary, and project-related data using PostgreSQL. It demonstrates practical SQL skills through database creation, table relationships, data retrieval, filtering, aggregation, and advanced analytical queries.

Objectives
- Create and manage relational database tables.
- Analyze employee information across different departments.
- Evaluate salary expenses and average salaries.
- Identify employees working on multiple projects.
- Analyze project assignments and completion timelines.
- Generate meaningful insights to support business decision-making.

Database Structure
The project consists of three relational tables:

1. Departments: Stores department IDs and department names.
2. Employees: Contains employee information, salaries, department assignments, and joining dates.
3. Projects: Stores project details, assigned employees, start dates, and end dates.

SQL Skills Demonstrated
- CREATE TABLE and database constraints
- SELECT statements
- INNER JOIN and LEFT JOIN
- WHERE and ORDER BY
- GROUP BY and HAVING
- Aggregate functions (COUNT, SUM, AVG, MAX)
- Subqueries
- Date and time functions
- DISTINCT and COALESCE

Business Questions Answered
The project explores 25 SQL business questions, including:
- Which employees earn more than 70,000?
- Which department has the highest average salary?
- What is the total salary expense per department?
- Which employees are assigned to multiple projects?
- Which employees are not assigned to any project?
- How many projects is each department handling?
- Which department has the highest number of employees working on multiple projects?

Project Outcome
This project demonstrates the application of SQL in transforming relational employee and project data into meaningful business insights. It strengthens practical database management, data querying, and analytical problem-solving skills.
